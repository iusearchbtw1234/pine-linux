# pine-linux
Pine Linux is an independent Linux distribution project built around one goal: making source-based Linux accessible to everyone.

Inspired by the flexibility of Gentoo and the accessibility of Arch Linux, Pine aims to combine the freedom of compiling software from source with the convenience of prebuilt binary packages. Users will be able to choose how they install and build their software without needing to wrestle with complicated configuration and maintenance.

Pine Linux is currently in its early stages, So dont expect a proper distro yet!
